# Tavi World

Original local-first pixel-art creature simulation featuring Tavi.

This repository contains the source for the existing simulation and a new original top-down pixel-RPG graphics edition. The owner retains final approval over consequential changes.

## Local run

Extract the release archive and run `START-TAVI-WORLD.bat` on Windows. Keep the local server at `http://localhost:8765/` to preserve the browser save origin. Export a save backup before testing.

## Graphics

Original retro handheld-RPG-inspired environments and character art; no Pokémon assets are used.

## Status

Graphics overhaul in development. Windows launcher not yet tested on a Windows machine.
