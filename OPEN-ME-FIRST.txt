TAVI WORLD — DETAILED CONTINUOUS OVERWORLD (2026-11-16)

THE WORLD IS ONE CONTINUOUS PIXEL MAP, NOT STITCHED ILLUSTRATED SCENES.
The native renderer now has 32px terrain textures, richer tree and decor sprites,
seamless biome color patches, more detailed water, grass, roads, buildings, and props.

TO RUN ON WINDOWS
1. Export your save in the existing Tavi World first.
2. Extract this ZIP into a new folder and close any older Tavi launchers.
3. Double-click START-TAVI-WORLD.bat in the extracted folder.
4. Open http://localhost:8765/ in the SAME browser to retain your saved Tavi.
5. For Ollama-powered thoughts, keep Ollama running and test under Profile > Settings.

To view what changed, open docs/forest-before-after.png and
 docs/house-before-after.png. The actual game screenshots are in docs/.

No scene-image panels are used by the game, and this update does not change
Tavi's movement, saved cognition, commitments, or model bridge.
Native Windows and live local Ollama still need verification on your computer.
