TAVI WORLD — GROUNDED AUTONOMY / NATURAL CONVERSATION EDITION

Close your old launcher, unzip this build to a new folder and run START-TAVI-WORLD.bat. Open http://localhost:8765/ in the same browser as before so Tavi can access his saved history.

Go to Profile > Settings. Keep your working Ollama model and enable advice. Open Connect > Talk and ask about a real memory or goal. When enabled, the initial message is "Considering your question…", then an original Ollama reply. Expand "Context supplied to the model" to review grounding anchors.

To test a self-directed action immediately: Profile > Settings > Invite Tavi to choose independently. If the model is unavailable, dialogue falls back to clearly labeled rule-based responses.

The Windows bridge, game save key, map, experiments, books, video studies and read-only web research remain compatible. See docs/GROUNDED-VOICE-RELEASE.md for limitations, safety, and tests.
